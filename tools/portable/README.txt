王正宁课题组网站 · 离线浏览包
================================

【Windows 电脑】
1. 先把压缩包完整解压到一个文件夹（不要在压缩软件里直接双击运行）
2. 双击「Open-Website.bat」
3. 浏览器会自动打开网站。浏览期间不要关闭弹出的黑色窗口，看完关掉它即可

   - 如果出现「Windows 已保护你的电脑」等安全提示，点「更多信息」→「仍要运行」
   - 如果浏览器没有自动打开，手动访问黑色窗口里显示的地址（如 http://localhost:8080/）

【Mac 电脑】
1. 解压后，右键点击「Open-Website-Mac.command」→ 打开
2. 首次运行如果提示安装「命令行开发者工具」，按提示安装后再打开一次（需要 Python 3）

【说明】
- 不需要联网，也不需要安装任何软件（Mac 除外）
- 不能直接双击 site 文件夹里的 index.html 打开：浏览器出于安全限制会拦截网页脚本，动画和交互都会失效
- 建议使用较新版本的 Chrome、Edge、Safari 或 Firefox
- 如果系统关闭了「动画效果」，网页会自动减少动画；想看完整效果，可在
  Windows 设置 → 辅助功能 → 视觉效果 中打开「动画效果」
